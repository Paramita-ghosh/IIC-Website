# UDBHAV 2026 - Official Website

This is a modern, animated event website for **Udbhav 2026**, the annual Youth Summit by IIC MNNIT Allahabad.

## Tech Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP (GreenSock), ScrollTrigger
- **Smooth Scroll**: Lenis
- **Start Command**: `npm run dev`

## Features
- **GSAP Animations**: Scroll-triggered reveals, staggered card animations, magnetic effects.
- **Lenis Smooth Scroll**: For a premium feel.
- **Custom Cursor**: Interactive cursor follower.
- **Responsive Design**: Fully mobile-optimized.
- **Glassmorphism & Neon Theme**: High-end cyber aesthetic.

## Folder Structure
- `src/components/`: All UI components (Hero, About, Events, etc.)
- `src/assets/speakers/`: Speaker images.
- `src/index.css`: Global styles and Tailwind theme.

## How to Edit
- Modify `src/components/Events.jsx` to update tracks.
- Modify `src/components/Schedule.jsx` to update timeline.
- Modify `src/components/Speakers.jsx` to update speaker list.
